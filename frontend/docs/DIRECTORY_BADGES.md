# Ярлыки в контактах

Каждая карточка показывает ровно один ярлык по старшинству:

| Приоритет | Ярлык | Цвет |
| --- | --- | --- |
| 1 | Джун | Лиловый |
| 2 | Активист | Голубой |
| 3 | Мастер | Мятный |
| 4 | Зам председателя | Золотой текст и контур |
| 5 | Председатель | Золотая заливка, тёмный текст |

Председатель и заместители берутся из `/leadership`, мастер — по точному
`master.user.user_id` в каталоге блоков. Категория участия читается прежним batch API.
Ни ФИО, ни текст поля `blocks`, ни категория участия не дают должность.
Смена ярлыка не меняет права или категорию участника; фильтр категории продолжает
фильтровать именно категорию, а не должность.

Дополнительных запросов нет. При потере доступа к каталогу ролей сохранённые роли
убираются; пока источник более старших ролей неизвестен, показывается
«Роль загружается…» / «Роль недоступна», а не неподтверждённый младший ярлык.
Сетевой сбой оставляет доступные данные с существующим предупреждением.
Короны, строка руководства над блоками, управление аккаунтом и фильтры сохраняются.
Длинный ярлык заместителя переносится между словами, чтобы не сжимать ФИО на телефоне.

Проверки: `directory-leadership.test.tsx`, `directory-category-batch.test.tsx`,
`directory-filters.test.tsx`.
