# Чат VK для задач

В форме создания задачи сохранены существующие две колонки. После исполнителей,
перед наблюдателями находится карточка «Уведомить чат VK». Переключатель по
умолчанию выключен; включение входит в состояние несохранённого черновика и в
идемпотентный запрос создания задачи. Смена очереди выключает рассылку, сохраняя
текст и остальные параметры задачи.

`TaskChatToggle` получает проекцию `/tasks/chat-context` для выбранной очереди и
списка исполнителей. Она не запрашивает VK. При выбранных исполнителях показаны их
имена; без исполнителей — уведомление всех участников чата. Предпросмотр свернут
по умолчанию и содержит только заголовок, команду, получателей и будущую ссылку.
Описание, вложения и ККР в сообщение не включаются.

Недоступный чат, закрытая очередь и отсутствие связей VK объясняются рядом с
переключателем. Чужие/удалённые данные после отказа доступа не сохраняются на
экране. Ошибка проверки чата не блокирует обычное создание задачи без рассылки.
Если проверка стала недоступна после включения, рассылку всегда можно выключить;
она никогда не превращается автоматически в упоминание всех. При изменении
ревизии привязки автор должен проверить новый чат и включить переключатель заново.

## Настройки

`TaskChatSettingsAction` добавляет кнопку «Настройки чата» на страницы блока и
мероприятия только по серверной capability `manage_chat`. Адрес
`?chat=settings` открывает тот же диалог, в том числе из пустого состояния формы.
В первой версии собственного чата или наследования для подмероприятий нет.

Сервер выдаёт отдельные `link_chat`/`unlink_chat`. Получение кода и отключение
передают `expected_revision`; отключение требует подтверждения в самом диалоге.
Сервисный аккаунт может отключить чат, но не получает код от имени человека.
Одноразовая команда `/site_bind …` хранится только в состоянии открытого диалога,
не попадает в URL, localStorage, логи или общий query cache. Её можно скопировать
кнопкой либо выделить вручную. Пользователь отправляет команду от своего VK в
нужную беседу, где он и HereBot должны быть администраторами.

Пока действует код, настройки проверяются раз в три секунды в активной вкладке.
Проверки прекращаются после подтверждения, смены ревизии, отзыва доступа, истечения
кода или закрытия диалога. Название чата приходит из проекции сайта, которую
обновляет бот; произвольный peer ID или список чужих чатов интерфейс не предлагает.

## Доставка

У созданной задачи `TaskChatDelivery` показывает `pending`, `sending`, `sent`,
`failed`, `partial` или `cancelled` из `task.chat_announcement`. Только задачи с
незавершённой отправкой перечитываются раз в пять секунд; старые задачи без рассылки
не создают дополнительных запросов. Кнопка повторной отправки доступна только по
`retry_chat_announcement`, использует ревизию доставки и никогда не создаёт задачу.

DTO находятся в `src/utils/api/taskChat.types.ts`, HTTP-клиент — в
`taskChat.api.ts`; импорт DTO в node-only инструменты должен идти из `.types.ts`.
`src/pages/Workspace/task-chat.test.tsx` проверяет состояния интерфейса, права,
черновик, идемпотентность и восстановление после ошибок;
`src/utils/api/tests/task-chat.test.ts` — wire contract и HTTP-параметры.
Браузерные проверки настоящей сборки находятся в `e2e/task-chat.spec.ts`.
DEV-демо с переключателем ролей показывает безопасное состояние «Чат не подключён»;
оно не имитирует подтверждение живым ботом и не отправляет сообщения.
