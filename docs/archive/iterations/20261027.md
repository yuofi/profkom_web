Одна публичная ревизия; повтор команды идемпотентен, устаревшая версия откатывает всю команду. Прямой выбор статуса исполнителя не назначает. ## Как разделены состояния

Общий статус задачи — в шапке. Расчётное состояние — у каждого исполнителя в блоке
ККР. Положительное решение требует фактическую сдачу либо разрешённую расчётную
дату; дата не выдумывается. Пустой выбор решения сохраняет прежний исход. После
успеха одноразовый выбор оценки очищается, поэтому последующая правка часов не
переутверждает работу незаметно.

Сохранены частные версии, причины, численные правила, роли и прежние ограничения
переходов. Для закрытого сезона разрешённая корректировка создаёт новую версию
итогов, старый снимок остаётся неизменным. Независимые очереди без команды не
получают фиктивные начисления. Подзадачи подмероприятия переносятся вместе с
мероприятием, не поодиночке; отдельный перенос независимых queue-задач прежним
контрактом не поддерживается. Legacy URL исправлений сохранён, проверка прав
председателя и заместителей согласована с backend.
