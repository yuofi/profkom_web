# Варианты без подложки и подписи роли

- **D — Типографика.** Мастерский блок — полужирный мятный текст, обычный блок спокойнее. [Скриншот](variant-D.png), [точный CSS](variant-D.css).
- **E — Вертикальная черта.** Тонкая мятная черта слева, без подложки, рамки и подписи роли. [Скриншот](variant-E.png), [точный CSS](variant-E.css).
- **F — Контурный значок.** Контурная корона перед названием блока, без заливки и подписи роли. [Скриншот](variant-F.png), [точный CSS](variant-F.css).

Использована одна существующая синтетическая карточка при ширине исходного интерфейса 1440 px. Фото, имя, группа и действия сохранены. Дополнительный обычный блок «Видеолаба» добавлен ТОЛЬКО в браузерный эскиз для сравнения; это не утверждение о членстве и не изменение базы. «· мастер» и подчёркивание убраны во всех эскизах.

D: акцент только цветом и жирностью. E: вертикальная черта, без прямоугольной рамки. F: контурная SVG-корона (14×14, fill=none); SVG создаётся только в DOM данного эскиза. Ни один вариант не применён к исходникам.

Все PNG: 362 × 241 px; визуальная проверка 3/3 пройдена. Для F сохранён [точный SVG значка](variant-F-icon.svg).
