# Решения владельца: правки ККР, шаблонов, трекера, рассылок и служебный аккаунт, 8 ноября 2026

> Датированная запись ответов владельца на разбор правок. Номера пунктов — как в разборе:
> А — учёт ККР, Б — заслуги и шаблоны, В — трекер. Запись не разрешает внешних действий:
> вся работа локальная (AGENTS.md).

## Учёт ККР на задаче

| Пункт | Решение |
| --- | --- |
| А1. Галочки вместо «Да/Нет» | Везде, где заполняют критерии: форма заслуги, исправление закрытых итогов, редактор шаблона. Названия критериев одинаковые на всех экранах |
| А1. Набор критериев | Пять признаков со своими множителями (ниже), в таком порядке. Сначала из таблицы владельца взяли восемь; 8 ноября владелец передумал: «Срочная задача», «Нудная / монотонная задача» и «Требуется ли физическая сила» убраны. Срочность учитывается только автоматически, по сроку задачи: `hours * (1 + 1 / sqrt(available_days + 1))` |
| А1. Раскладка признаков | Признаки в окне ККР и в форме заслуги стоят криво: разное число в строке и разная длина. Варианты ровной раскладки показать снимками |
| А2. Кнопки учёта | Секция «Учёт работы и ККР» на задаче и окно учёта: кнопки открытия и сохранения слишком маленькие и не в стиле сайта. По снимкам ближе всего вариант В: сводка и кнопка во всю ширину в секции, нижняя панель окна с «Закрыть» и «Сохранить ККР». Некрасиво поле часов, разбивка по исполнителям на телефоне выходит за границы. Второй круг вариантов снимками |
| А3. «Позже» | Убрать. Окно закрывают ✕ и Esc, ККР при закрытии задачи остаётся необязательной |

## Учёт выполненной работы (особые заслуги и волонтёры)

| Пункт | Решение |
| --- | --- |
| Б1. Одинаковые значения для всех | «Председская ККР» — вся страница «Учёт выполненной работы». Галочка «одинаково для всех»: одни часы, оценка и дата на всех получателей, отдельного человека можно поправить. В новой записи галочка включается сама, когда получателей двое и больше; снятая вручную больше сама не включается. При правке записи она включена, только если у всех получателей уже одинаковые значения |
| Б8. Список записей | Записей может быть много. По снимкам ближе вариант Б (таблица), но: у получателей бывают разные часы и ККР, поэтому сводные часы и ККР записи неверны; нужны компактные чипы получателей вместо имён; нужны фильтры и поиск. Второй круг вариантов снимками |
| Б9. История | Правки записи (в том числе через исправление закрытых итогов) не писались в историю — ошибка исправлена. Показ: вариант В — журнал изменений сезона на странице учёта (переключатель «Записи / Журнал изменений», правки по дням, фильтры по команде и участнику). История в самой записи остаётся |

## Шаблоны ККР

| Пункт | Решение |
| --- | --- |
| Б2. Авторство | Показывать автора и того, кто последним изменил шаблон. Дату создания не показывать |
| Б3. Чужие шаблоны | Создание уже ограничено командами, где человек ведёт ККР. При применении показывать только шаблоны этой команды, личные и «Весь Профком» |
| Б4. Фильтры | Поиск по названию, команда, личные/командные; архивные скрыты по умолчанию. Сезона у шаблона нет. Списки «Команда» и «Вид» одного размера и вида |
| Б5. Правка | Форма раскрывается прямо в карточке шаблона (отменяет размещение над списком из SE-27) |
| Б6. «Отвязать шаблон» | Убрать. Если сохранение не проходит из-за шаблона, сообщение предлагает сохранить без шаблона |

## Трекер

| Пункт | Решение |
| --- | --- |
| В1. Зависимости | Предупреждение держится, пока задача, от которой зависят, не «Закрыта» (как сейчас). В окне «Добавить связь» — вариант Б: виды связи карточками с пояснением, недоступный вид приглушён |
| В2. Цвета статусов | Раскрасить статусы связанных задач, подзадач и подобных списков, где статус сейчас простым текстом. Цвета календаря и диаграммы Ганта привязать к нынешним статусам. Вариант А — цветная плашка; все плашки статусов одной ширины |
| В3. Backspace в чеклисте | Backspace только стирает текст; пустой пункт удаляется крестиком «×» |
| В4. Чеклист в комментарии | Отмечать может любой читатель задачи; комментарий не помечается «изменён»; отметка видна в истории |
| В5. Удаление комментария | Через меню «⋯». Удалить может любой, кто может комментировать задачу. Заглушки не остаётся, удаление видно в истории задачи. Вариант Б: пункты меню со значками, короткое подтверждение «Удалить комментарий? Удалить / Отмена» в строке комментария |
| В6. «Взять в работу», «Сдать результат» | Убрать везде, включая обращения в поддержку. Результат пишут в комментарии; блок «Результаты работы» остаётся только для уже сданных результатов |
| В7. ККР в аналитике | Не ошибка: за задачу выставилось 0 баллов |
| В8. Привязка очереди | Своего параметра у очереди нет. На странице очереди видно команду и сезон, если он есть у команды или мероприятия; если сезон мероприятия закрыт или подводит итоги, видно, что новые задачи создать нельзя. Вариант В: у названия плашки команды и сезона с состоянием, «Создать задачу» неактивна с коротким пояснением и полной причиной в подсказке; в каталоге — столбец «Команда и сезон» |
| В9. Ключ очереди | Латинские заглавные буквы и цифры, первым символом — буква; строчные переводятся в заглавные |

## Рассылки

| Пункт | Решение |
| --- | --- |
| Понятные ошибки | Отказ показан на тестовом сайте под замом председателя. Воспроизводится только локально; если не воспроизводится — сообщить владельцу. Тексты отказов в рассылках — конкретные: кто может и к кому обратиться. Голый отказ «http_403: Не удалось выполнить запрос» локально не воспроизвёлся; его разбирает другой агент, в этот набор правок не входит |

## Служебный аккаунт

| Пункт | Решение |
| --- | --- |
| Назначение | Для отладки. Нигде не отображается: ни в контактах, ни в выборе исполнителей и других списках людей |
| Вход | Только логин и пароль; логин `root`. После 10 неудачных попыток с одного адреса за 15 минут вход под ним закрывается на время; у обычных аккаунтов ограничения нет — владелец согласен. Логин и хеш пароля задаются в `.env` сервера, без интерфейса на сайте; смена — правкой `.env` и перезапуском. Без VK ID и без привязки бота, срок обязательной привязки на него не действует |
| Права | Полный доступ ко всем функциям, включая консоль бота и действия «только председателя». Проверка обновлений, обновление и откат бота у него выключены с пояснением: сервер обновлений требует VK автора запроса, а у служебного аккаунта VK нет. Владелец оставил так |
| Подпись | В истории и уведомлениях — «Сервисный аккаунт» |
| Уведомление о входе | Только на сайте, председателю и мастеру блока IT: время, IP, браузер. О неудачных попытках — после трёх подряд. Вариант Б: заголовок со значком щита и вторая строка «время · IP · браузер»; неудачные попытки — красный заголовок с числом попыток. Полная строка браузера не хранится |
