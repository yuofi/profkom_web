# Предложения по раскладке страниц: на рассмотрение владельцу

**Ничего из этого не применено к сайту.** Код приложения не менялся. В папке только макеты (`mockup.html`), снимки «до» и «после» и описания.

**Цвета, значки и шрифты не тронуты.** Макеты меняют только порядок блоков, их группировку, сетку и отступы.
- Цвета: только существующие токены `var(--…)` и те же `color-mix()`, что уже есть в сборке.
- Значки: только имена из списка `ICONS` (`frontend/src/components/icons.ts`, 52 имени), новых SVG нет.
- Шрифты: GoogleSans и Material Symbols Rounded, побайтные копии из `frontend/src/assets/fonts` (лежат в `assets/fonts/`).

Снимки сделаны на локальном стенде с синтетическими данными, сборка r1-final ветки `audit/qa-20261031` @ 8b98c52.

## Как смотреть
Откройте `D-xx/mockup.html` в браузере, сеть не нужна. В углу всегда есть метка «Макет D-xx, не применено» и переключатель «До / После» (в D-04…D-06 он называется «Было / Стало»). «До» показывает нынешнюю страницу без изменений. Подробности, замеры и список файлов для каждого предложения лежат в `D-xx/README.md`.

## Что проверено (2026-11-01)
- **Цвета.** Все цветовые литералы и `color-mix()` каждого макета сверены со снимком страницы и с CSS сборки r1-final: новых нет. Кроме того, у каждого видимого элемента «После» взяты вычисленные цвета: все они есть на странице «До» или в сборке.
- **Значки, шрифты, сеть.** Все значки из списка `ICONS`, каждый рисуется глифом, а не текстом. Новых SVG нет. В макетах только GoogleSans и Material Symbols Rounded. Внешних адресов нет, макет открывается без сети, ошибок в консоли нет.
- **Метка.** «Макет D-xx, не применено» видна в обоих видах на 1440 и 390 px.
- **«До».** Вид «До» совпадает с живыми снимками «до»: отличаются только метка макета и сглаживание отдельных глифов. D-02 сверялся по кадру списка при сборке макета.
- **Ничего не потеряно.** Тексты, ссылки, кнопки и подсказки видов «До» и «После» сравнены построчно. Пропадает только то, что предложено убрать: «Подробнее», «Открыть», повторы фраз и подписей. Это и неочевидные потери перечислены в разделе «Риск» каждого README. В D-08 и D-09 проверено попаданием по точкам: углы и середина карточки ведут в профиль или материал, ссылки на блоки внутри карточки контакта остаются отдельными.
- **Ширина.** Горизонтальной прокрутки нет на 360, 768, 1024, 1280, 1440 и 1920 px.
- **Файлы.** Все файлы из списков «если одобрить» существуют в ветке `audit/qa-20261031`.

Исправлено при проверке:
- В макетах D-04…D-09 шапка страницы была без скруглённых углов. Это дефект снимка: в нём потерялось правило `border-radius`. Углы возвращены тем же правилом, что в D-01…D-03, а снимки «После» пересняты. Больше на снимках ничего не изменилось.
- В README добавлены риски:
  - D-02: на телефоне нет подсказки с остальными исполнителями;
  - D-03: пояснение о сезоне на телефоне не видно;
  - D-05: кнопки в шапке меняют стиль, а пустую карточку «О блоке» нужно скрывать;
  - D-07: из подписи убраны «Предварительные итоги», а дату утверждения нужно сохранить.
- Снимки страниц `source.html` и `source-mobile.html` убраны из папки. Макеты их не загружают: вид «До» содержит страницу целиком. Копии остались в локальной рабочей папке аудита.
