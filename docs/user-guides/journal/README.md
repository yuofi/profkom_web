# Гайды в формате «Журнал»

Пять редакций для локального просмотра от 12 ноября 2026 года. Тексты сверены с
интерфейсом и правилами сайта. Каждый JSON — исходник `JournalDocument` версии 1
для материала с `content.format = "journal-v1"`.

| Исходник | Содержание | Доступ |
| --- | --- | --- |
| [tracker.json](tracker.json) | От поиска задачи до передачи результата; пример с афишей, скриншоты и рассылка VK | Всем участникам |
| [overview.json](overview.json) | Профиль, команды, разделы сайта, уведомления и помощь | Всем участникам |
| [kkr.json](kkr.json) | Условия, оценка исполнителей, сроки, сводка и исправления | `leadership` |
| [authoring.json](authoring.json) | Создание, структура, оформление, доступ и отдельная публикация | Всем участникам |
| [formatting.json](formatting.json) | Markdown, изображения, ссылки, блоки журнала и HTML на коротких примерах | Всем участникам |

Тексты используют самостоятельные разделы, карточки фактов, шаги, сравнения,
раскрываемые подробности и переключаемые примеры. В справочнике есть небольшая
настоящая HTML-вставка и готовый код для повторения.

## Перенос в материал

- Названия, описания, аудитории и стабильные ID опубликованных материалов остаются
  в [исходном каталоге](../catalog.json). Его хеши относятся к прежним публикациям;
  эта локальная редакция их не меняет.
- Ссылки между гайдами в JSON ведут на ID из этого каталога. Для отдельного стенда
  нужно заменить их на ID локальных копий **во всех текстовых полях**.
- `file-guide-tracker-create` соответствует [tracker-create.png](../images/tracker-create.png),
  а `file-guide-tracker-task` — [tracker-task.png](../images/tracker-task.png).
  Картинки загружаются штатным API как файлы соответствующего материала; после
  завершения загрузки подставляются полученные `file_id`. Оба изображения —
  снимки интерфейса с вымышленными данными.
- Перед публикацией нужно скомпилировать документ, проверить отсутствие
  диагностик, сохранить черновик, выставить аудиторию и отдельно опубликовать.
  Один только JSON не предоставляет доступ к чужим файлам.

## Локальный просмотр

В рабочей копии стенд и его проверки находятся в
`.local/design/guide-journal-preview-20261112/`. `manifest.json` содержит текущий
локальный адрес и PID двух процессов. Стенд использует настоящие страницы сайта,
отдельную синтетическую SQLite и локальную подмену хранилища; кнопки выбора роли
на стартовой странице входят в тестовые аккаунты.

В `api-verification.json` записаны проверки сохранения, публикации, байтов
изображений и аудиторий; в `browser-verification.json` — проверки всех пяти
страниц на компьютере и телефоне. Скриншоты лежат рядом. Эти файлы — локальные
артефакты, они не входят в Git.

База создаётся заново при запуске стенда, а изображения живут в памяти его API.
Локальные правки через редактор не обновляют JSON-исходники автоматически.
Рабочие публикации этим стендом не меняются.
