## 1. Создайте черновик

Откройте **«Материалы» → «Создать материал»** и заполните:

| Поле | Пример |
| --- | --- |
| Раздел и блок | **Гайд блока → ваш блок** |
| Название материала | Как подготовить афишу |
| Краткое описание | Размеры, согласование и передача макета |
| Текст материала | Первые шаги инструкции |

Нажмите **«Создать черновик»**. Название и краткое описание обязательны. Картинки и оформленные вставки добавляются после первого сохранения.

```profkom-html id=embed-authoring-rights
<details class="guide-card guide-tone-neutral guide-compact">
<summary>Нет кнопки создания или редактирования?</summary>
<p>Гайд блока создают и редактируют мастер этого блока, его заместители, председатель и заместители председателя. Обратитесь к одному из них.</p>
<p>«Общий документ» и «КМБ» — отдельные разделы: их создаёт руководство сайта и назначает редакторов. HTML-вставки доступны только в «Гайде блока».</p>
</details>
```

## 2. Соберите инструкцию

Начните с действий читателя. Вместо «Заполните необходимые данные» напишите: **«Введите название и нажмите “Создать черновик”»**.

- Разделы обозначайте `##`. **Оглавление появится автоматически.** Второе название в начале текста не нужно.
- В **«Вставить»** выберите плашку, таблицу, изображение, кнопку или другой готовый блок. Заполните поля и нажмите **«Вставить в гайд»**.
- При первой вставке отметьте **«Включить оформленные вставки в этом гайде»**.
- Картинку загрузите в этот материал. Для вставок подходят **PNG, JPEG и WebP**. Обрежьте лишнее и добавьте описание изображения.

```profkom-html id=embed-authoring-template
<details class="guide-card guide-tone-neutral">
<summary>Заготовка: скопируйте и заполните</summary>
<pre><code>Поможет подготовить афишу и передать её на публикацию.

## Что подготовить
Дата, место, текст и размер изображения.

## Что сделать
1. Соберите макет.
2. Согласуйте его с ответственным.
3. Приложите готовое изображение и исходник к задаче.

## Как проверить результат
Макет согласован, оба файла открываются из задачи.</code></pre>
</details>
```

## 3. Выберите читателей

В параметрах откройте **«Кто видит гайд»**:

| Аудитория | Кто прочитает |
| --- | --- |
| **Только свой блок** | Участники и руководство блока; председатель и его заместители |
| **Все активисты** | Все активные аккаунты сайта |
| **Руководители и заместители** | Руководство сайта, блоков, мероприятий и их частей |

Смена аудитории применяется отдельно: **она не сохраняет текст и не публикует черновик**. Прямая ссылка не обходит ограничения чтения.

## 4. Проверьте и опубликуйте

1. Откройте **«Предпросмотр»**, выберите ширину **«Телефон · 390 px»**.
2. Проверьте ссылки, читаемость картинок и отсутствие ошибок.
3. Нажмите **«Сохранить черновик»**, дождитесь сохранения.
4. Нажмите **«Опубликовать сохранённый черновик»**. Откройте страницу материала, проверьте результат и переходы из оглавления.

```profkom-html id=embed-authoring-publication
<div class="guide-grid-2">
<section class="guide-card guide-tone-neutral guide-compact"><p><strong>Сохранить черновик</strong></p><p>Читатели продолжают видеть прежнюю публикацию.</p></section>
<section class="guide-card guide-tone-success guide-compact"><p><strong>Опубликовать</strong></p><p>Читатели получают сохранённую версию. Несохранённые правки в неё не попадут.</p></section>
</div>
```

## Если не получилось

| Ситуация | Что проверить |
| --- | --- |
| Читатели видят старый текст | Была ли нажата **публикация**, а не только сохранение? |
| Видно HTML-код | Включены ли оформленные вставки? Обычный блок `html` показывает код. |
| Публикация недоступна | Исправьте указанные ошибки оформления и сохраните черновик. |
| Данные изменились | Другой редактор мог сохранить правки. Сначала перечитайте свежую версию. |

Для обновления готового гайда откройте **«Редактировать материал»** и повторите шаг 4. **«Готово»** только закрывает редактор.
