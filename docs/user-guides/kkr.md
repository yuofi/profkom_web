ККР задачи заполняют **после её закрытия**. Часы, оценки и признаки сохраняются одной кнопкой.

## 1. Сначала проверьте

```profkom-html id=embed-kkr-check
<section class="guide-card guide-tone-info guide-compact">
<ul>
<li><strong>Есть сезон.</strong> У задачи блока его выбирают отдельно в параметрах.</li>
<li><strong>Задача закрыта.</strong> Комментария с результатом недостаточно.</li>
<li><strong>Есть исполнители.</strong> Проверьте, кто действительно выполнял работу.</li>
<li><strong>Вам доступна оценка.</strong> Откройте «Учёт работы и ККР» → «Оценить работу».</li>
</ul>
<p><a class="guide-button" href="/tasks">Открыть трекер</a></p>
</section>
```

В самостоятельной очереди, не связанной с блоком или мероприятием, ККР недоступен. Служебный контрольный эпик тоже не оценивается.

```profkom-html id=embed-kkr-access
<details>
<summary>Кто может выставлять ККР?</summary>
<ul>
<li>Председатель, его замы, мастер HR и замы мастера HR — во всех областях.</li>
<li>Мастер и замы — в своём блоке.</li>
<li>Главорг и замы — в своём мероприятии и его подмероприятиях.</li>
<li>Ответственный и замы — в своём подмероприятии.</li>
<li>Назначенный HR-куратор — в закреплённой области.</li>
</ul>
<p>Авторство задачи или владение очередью само по себе этих прав не даёт. Закрыть чужую задачу только благодаря праву оценки также нельзя: обычно её закрывает автор.</p>
</details>
```

## 2. Заполните и сохраните

1. Отметьте **общие признаки задачи**: они применяются ко всем учитываемым исполнителям.
2. Для каждого человека укажите **часы и оценку**. Дробные часы допустимы: например, `2,5`.
3. Если человека учитывать не нужно, выберите **«Исключить»**. Проверьте и прежних исполнителей.
4. Нажмите **«Сохранить ККР»** и дождитесь **«ККР сохранён»**.

```profkom-html id=embed-kkr-example
<section class="guide-card guide-tone-success guide-compact">
<p><strong>Пример: два исполнителя</strong></p>
<table>
<caption>Заполненные поля</caption>
<thead><tr><th scope="col">Кто</th><th scope="col">Часы</th><th scope="col">Оценка</th></tr></thead>
<tbody><tr><td>Анна</td><td>2,5</td><td>1</td></tr><tr><td>Илья</td><td>1</td><td>1,5</td></tr></tbody>
</table>
<p>Часы указываются каждому отдельно. Если Илья в итоге не участвовал, отметьте «Исключить», а не ставьте отрицательную оценку.</p>
</section>
```

| Оценка | Что означает для расчёта |
| --- | --- |
| **−1** | Отрицательное начисление |
| **0** | Ноль — работа уже оценена |
| **1** | Обычное положительное начисление |
| **1,5** | Положительное начисление с множителем 1,5 |

Пустое поле — **ещё не заполнено**, а не ноль. Без часов и оценки хотя бы у одного неисключённого исполнителя весь набор не сохранится. **«Закрыть»** внизу окна закрывает окно, не сохраняет ККР.

## 3. Учтите сроки

```profkom-html id=embed-kkr-time
<section class="guide-card guide-tone-warning guide-compact">
<p><strong>Для ККР используется время закрытия задачи.</strong> Время комментария или позднейшего заполнения оценки его не заменяет. Даты в форме — московские.</p>
</section>
```

**Пример расчёта:** на задачу дали ровно 3 дня; работа заняла 2 часа; оценка `1`; признаки не выбраны. Множитель срочности — `1,5`.

| Когда закрыли | Исходный ККР |
| --- | ---: |
| Вовремя | **3** |
| На 24 часа позже | **2** |
| На 48 часов позже | **1** |
| На 72 часа или больше позже | **0** |

Это значения **до коэффициента источника в сезоне**. Срок считается по точному интервалу, включая неполные сутки.

```profkom-html id=embed-kkr-formula
<details>
<summary>Формула и множители признаков</summary>
<p>Положительный ККР = часы × оценка × признаки × срочность × срок.</p>
<ul>
<li>Срочность = 1 + 1 / √(дни от выдачи до дедлайна + 1).</li>
<li>Срок = max(0; 1 − дни просрочки / 3).</li>
<li>Без дедлайна оба множителя равны 1.</li>
<li>При оценке −1 начисление отрицательное; просрочка его не уменьшает. При 0 результат всегда нулевой.</li>
</ul>
<table>
<caption>За что увеличивается ККР</caption>
<thead><tr><th scope="col">Признак</th><th scope="col">Множитель</th></tr></thead>
<tbody>
<tr><td>Уникальная задача</td><td>1,2</td></tr>
<tr><td>Очное присутствие</td><td>1,2</td></tr>
<tr><td>Творческий подход</td><td>1,3</td></tr>
<tr><td>Общение с администрацией или людьми вне вуза</td><td>1,1</td></tr>
<tr><td>Выполнение в определённое время</td><td>1,1</td></tr>
</tbody>
</table>
<p>Выбранные множители перемножаются. Например, очное присутствие и творчество: 1,2 × 1,3 = 1,56.</p>
</details>
```

## 4. Проверьте результат

После сохранения строка **«Учёт работы и ККР»** обновится. Сводка нужного сезона пересчитывается автоматически; общую сводку видят председатель, его замы, мастер HR и его замы.

| Что произошло | Что проверить |
| --- | --- |
| Начисления нет | Сезон задачи, исключение исполнителя, подтверждение сохранения |
| Получился ноль | Оценку `0`, часы `0`, просрочку от 72 часов, коэффициент источника |
| Сумма отличается | Коэффициенты источников и отдельные бонусы мастеров |

Если причина не найдена, передайте поддержке **ссылки на задачу и сезон, часы, оценку и время сохранения**. Не создавайте дубликат начисления.

## 6. Исправьте ошибку

- **Сезон не закрыт:** откройте оценку, исправьте поля, сохраните ещё раз.
- **Сезон закрыт:** исправляют председатель, его замы или мастер HR; нужна **«Причина исправления»**. Создаётся новая версия итогов.
- **Данные изменил коллега:** нажмите **«Загрузить сохранённые»**, сверяйте поля с актуальными значениями.
- **Ошибка в датах:** используйте отдельное действие **«Изменить даты задачи»** с причиной, если оно доступно. Не компенсируйте дату изменением часов.

Как выбрать сезон и закрыть задачу — [в инструкции по трекеру](GUIDE_TRACKER).
