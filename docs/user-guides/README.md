## Подготовка публикации

`GUIDE_TRACKER`, `GUIDE_OVERVIEW`, `GUIDE_KKR`, `GUIDE_AUTHORING` и
`GUIDE_FORMATTING` — ссылки на соответствующие материалы. При публикации они
заменяются на `/materials/<id>` из подтверждённого каталога публикации.
`IMAGE_TRACKER_CREATE` и `IMAGE_TRACKER_TASK` — контекстные файлы гайда трекера:
загрузить PNG из `images/` штатным API вложений, завершить проверку файла и
подставить выданный `file_id` в `file:...`. Подписанные URL хранилища не сохранять.

Иллюстрации сняты с настоящего интерфейса на синтетических данных. Это примеры,
а не снимки данных участников. Оглавление строится автоматически из заголовков. Кнопки и ссылки внутри текста
используют Markdown-якоря `#section-N`; новые заголовки требуют повторной проверки
этих переходов.

Порядок обновления: сохранить черновик, проверить предпросмотр и права читателей,
опубликовать, перечитать через API и браузер на компьютере и телефоне. Аудиторию
ККР менять только на `leadership`: ручной список пользователей устареет при
смене должностей. Остальные материалы — `everyone`.
