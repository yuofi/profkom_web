# Руководства по сайту

Пять руководств находятся в «Материалы → Общие документы» в формате `journal-v1`.
Актуальные исходники — JSON в [journal/](journal/README.md). Прежние `.md` сохранены
как предыдущая редакция; их не нужно публиковать поверх новых материалов.

| Инструкция | Аудитория |
| --- | --- |
| [Как работать с трекером](journal/tracker.json) | Все активные участники |
| [Руководство участника](journal/overview.json) | Все активные участники; без административных функций и ККР |
| [Как заполнять ККР](journal/kkr.json) | Действующие руководители и заместители |
| [Как создавать гайды](journal/authoring.json) | Все активные участники |
| [Markdown, HTML и журнал](journal/formatting.json) | Все активные участники |

Адреса, ID, аудитории, версии и контрольные суммы опубликованных источников:
[catalog.json](catalog.json). `revision` — текущая версия материала,
`published_revision` — версия последней публикации текста; перенос раздела
не публикует текст заново. Результаты выкладки:
[Journal — 12 ноября](../operations/GUIDES_JOURNAL_RELEASE_20261112.md).

## Подготовка публикации

Ссылки между гайдами в JSON уже ведут на стабильные production ID из каталога.
Для отдельного стенда заменять их во всех текстовых полях. Локальные обозначения
`file-guide-tracker-create` и `file-guide-tracker-task` нужно заменить на файлы,
принадлежащие материалу: соответствие для production записано в
[journal/README.md](journal/README.md). Подписанные URL хранилища не сохранять.

Иллюстрации сняты с настоящего интерфейса на вымышленных данных. Оглавление
строится из разделов журнала; у каждого раздела есть устойчивый ID. После
переименования ID нужно проверить внутренние ссылки.

Порядок обновления: сверить текущую версию и источник, проверить предпросмотр,
сохранить черновик, отдельно опубликовать, перечитать результат через API и
проверить на компьютере и телефоне. Конфликт версий нельзя обходить перезаписью.
Аудитория ККР — `leadership`, чтобы доступ следовал за действующими должностями;
остальные четыре материала — `everyone`.

## Редактура

- Строить гайд вокруг действий читателя; оставлять короткие шаги и проверку результата.
- Выносить ключевые значения в карточки фактов, условия — в цветные заметки.
- Различать заголовки разделов, подписи карточек и выделения внутри текста.
- Редкие случаи и большие скриншоты раскрывать по запросу; варианты показывать переключателем.
- Не повторять справочник в каждом гайде: ссылаться на нужную инструкцию.
- Сверять подписи кнопок, права и ограничения с кодом; проверять ширину 390 px.

Предыдущая редактура: [сокращение от 12 ноября](../operations/GUIDES_EDITORIAL_20261112.md).
