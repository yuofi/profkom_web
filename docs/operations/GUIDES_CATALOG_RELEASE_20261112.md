# Гайды в «Общих документах» — 12 ноября 2026

На production `https://profcom-cmc.ru` обновлены backend и frontend до
`de8aad1805b82653b13737757627450ad2796109` из `release-1`. Пять новых руководств перенесены из

источники и render-артефакты, владельцы, права редакторов и аудитории сохранены.
Гайд по ККР по-прежнему доступен только действующим руководителям и заместителям.

## Изменение

Добавлено необязательное `materials.catalog_section`. Это только размещение в
каталоге; `kind` продолжает определять тип материала и прежние правила.
Фильтрация и группировка используют переопределение, если оно задано.

Председатель, заместители и сервисный аккаунт меняют раздел отдельным
revision-protected PATCH: `catalog_section: "general"`. Команда не создаёт
черновик и не публикует текст. `null` возвращает исходный раздел по типу.
В этой операции у пяти материалов `revision` изменился с 8 на 9;
последняя публикация текста остаётся прежней. ID и SHA: [каталог](../user-guides/catalog.json).
