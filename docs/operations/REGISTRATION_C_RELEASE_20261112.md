## Откат

Последнее frontend-обновление можно откатить на
`sha256:59c765fc73a72694bc29f5eb1452c23608db2824f2394d9fc2056c49359a4964`
без изменения БД и backend. Предыдущая пара до регистрации:

- backend `sha256:17ebe862e079bd8e305c01ccc9aa52ad7904c2b4e50def7004746a391c6debbc`;
- frontend `sha256:81a54258051179a204b27ac99e1823510982228b56a94d9811140cdd85973859`.

Меняется только нужный image в `/opt/profkom/compose.production.json`, затем
`docker compose -p profkom_web -f /opt/profkom/compose.production.json up -d --no-deps --no-build --pull never <service>`.
Для пары сначала backend, затем frontend; при повторном использовании старого
frontend — `nginx -t` и reload, чтобы обновить адрес backend.
Бэкап не накатывать поверх новых пользовательских записей. Старый код читает
новый JSON, но снова допускает незаполненное отчество: это функциональный откат.
Любой будущий откат требует актуального разрешения и свежего preflight.
