## Скорость HTML

GET переиспользует проверенные сериализованные JSON-байты содержания; сессия, права, аудитория и метаданные проверяются заново. Компиляция выполняется при работе с черновиком, вне SQLite writer lock. Чтение не компилирует HTML и не запрашивает S3.

Локальная синтетика на M4 Pro, ASGI gzip level 5/min512: по 800 запросов на формат (8 серий × 100 одновременно), p95 HTML/Markdown = 0,970 для 120 элементов, 0,977 для 500 и 1,029 для 1495. Все 5 040 измеренных ответов — 200. Это не замер capacity production и не смешанная нагрузка обычных API. Последовательные большие документы добавляют 0,57–0,79 мс; подробные условия сохранены в `.local/logs/guide-html-ready-20261112/REPORT.md`.

## Откат

До открытия нового backend предусмотрен возврат предыдущих образов и полностью завершённого frozen snapshot через backup API при остановленных писателях. Снимок сверяется с полным manifest; возможный старый `-journal` сохраняется отдельно до установки восстановленной базы.

**После появления новых записей и публикации этих гайдов старый backend запускать нельзя:** он не знает HTML-формат и трактует `leadership` как обычную аудиторию блока. Нельзя автоматически восстанавливать прежнюю БД поверх новых пользовательских данных. Нужен совместимый backend с исправлением; при необходимости флаг можно выключить для новых HTML-записей, сохранив чтение уже опубликованных. Ошибку отдельного гайда исправлять versioned API или штатным обратимым удалением, не восстановлением всей базы.
