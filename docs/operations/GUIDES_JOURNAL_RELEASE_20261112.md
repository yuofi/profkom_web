## Откат

До открытия нового backend допустим возврат frozen snapshot через backup API
только при остановленных писателях и полной проверке manifest. `-wal/-shm/-journal`
обрабатываются только после остановки backend. Неполная остановка пары возвращает
прежние сервисы без замены БД.

**После открытия писателей нельзя восстанавливать всю БД поверх новых записей.**
Ошибки пяти гайдов исправляются или откатываются к сохранённым исходникам через
PATCH/publish с CAS; чужая правка вызывает отказ, а не перезаписывается.

Для возврата образов `fde504c` сначала нужен откат содержания, затем проверка при
остановленных писателях: во **всей** таблице `materials` должно быть ноль
`journal-v1` в публикациях и черновиках, **включая удалённые материалы**. Проверка
не ограничена этими пятью гайдами. Если Journal ещё используется, скрипт не включает
старые образы, поднимает текущий совместимый runtime и требует исправления вперёд.
При image rollback БД не заменяется; readiness проверяется локально и через HTTPS.
