## Сохранность и переключение

Перед отключением выполнена репетиция на серверных копиях, включая запуск
прежнего образа на мигрированной копии. Реальные базы на компьютер не переносились.
SQLite-копии получены только backup API. PostgreSQL репетировался в отдельном
контейнере, внутренней сети без опубликованных портов и с синтетическим VK.

Бот остановлен первым; exit0 и финальный отчёт принят прежним сайтом. Автоматика
временно остановлена под deploy-lock. Затем включён maintenance503 и остановлен
backend. Сняты финальные SQLite backup API, PostgreSQL dumps обеих non-template БД
и globals. PostgreSQL-контейнер и его volume не пересоздавались и не перезапускались.

Финальная SQLite повторно мигрирована новым образом дважды и проверена прежним
образом. В production установлена эта проверенная копия через backup API,
сохранение владельца/прав и атомарную замену при остановленных writers.

- Сохранены 83 прежние таблицы сайта и 759 строк. Проверены прежние столбцы,
  значения, ID, FK, индексы, триггеры и views.
- Единственное разрешённое изменение прежнего значения — `published_body`
  **одной автоматической заглушки** гайда: прежний и новый тексты точно совпадают
  с известными сгенерированными шаблонами. Авторские материалы, остальные поля
  и все ID сохранены. Произвольный текст с флагом placeholder проверка запрещает.
- Созданы шесть пустых таблиц чатов/удаления блока и два nullable-поля
  `block_metadata`. Бессезонность задач не требовала перестройки таблицы tasks.
- В PostgreSQL сохранены все восемь прежних таблиц, их строки, столбцы, названия
  чатов, индексы и sequences. Добавлены только две пустые таблицы доставки.
- Второй запуск каждой миграции ничего не изменил. `integrity_check=ok`,
  нарушений FK нет; SQLite остаётся в DELETE.

Два отказа подготовительной репетиции были безопасными проверочными отказами:
сначала обнаружено точное обновление заглушки, затем исправлено неверное ожидание
помощника, будто `chats.title` — новый столбец. Он уже есть в v2.5.1; проверка теперь
строго сохраняет все его старые значения. До успешной репетиции production не менялся.
