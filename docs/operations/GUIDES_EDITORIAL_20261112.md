# Сокращение пользовательских гайдов — 12 ноября 2026

Все пять ранее опубликованных инструкций переработаны после замечания о чрезмерном
объёме. Вместо последовательного пересказа интерфейса — короткие действия, примеры,
таблицы и выделенные условия. Новая редакция опубликована на `profcom-cmc.ru` через
API материалов. Адреса и аудитории сохранены; приложение не пересобиралось и не
перезапускалось.

## Изменения

- **Обзор сайта:** три первых действия, карта разделов, карточки команд и помощь.
  Только возможности обычного активиста, без администрирования и ККР.
- **Трекер:** найти работу, создать задачу, позвать команду, принять результат.
  Один пример афиши проходит через статусы. Два снимка настоящего интерфейса на
  синтетических данных раскрываются отдельно; пояснения ошибок также свёрнуты.
- **ККР:** предварительные условия, четыре шага заполнения, таблица двух
  исполнителей и пример изменения начисления при просрочке. Формула, права и редкие
  случаи раскрываются по запросу.
- **Создание гайда:** четыре шага от черновика до публикации; одна копируемая
  заготовка. Синтаксис не дублируется.
- **Оформление:** шпаргалка Markdown и три работающих HTML-примера с раскрываемым
  кодом. Удалены длинные перечни тегов и технические рассуждения.

Названия карточек не являются заголовками: автоматическое оглавление содержит
только основные разделы. Важные ограничения остаются рядом с соответствующим
действием, а не скрываются в справке.

## Фактическая и визуальная проверка

Инструкции сверены с действующим кодом форм и API:

- Создание, исполнители и статусы: `TaskCreateForm`, `TrackerTaskDetail`,
  `TaskStatusMenu`, `backend/tracker.py`, `backend/task_seasons.py`.
- Чат и повторная отправка: `TaskChatAnnouncement`; HTML ограничен материалами,
  описания и комментарии задач используют Markdown.
- ККР: `accounting_batch.py`, `access.py`, `season_summaries.py`, `merit_rules.py`,
  `UnifiedKkrEditor`. Пример расчёта исполнен чистой функцией из `database.py`:
  2 часа, оценка 1, срок 3 дня дают 3 / 2 / 1 / 0 при задержке 0 / 24 / 48 / 72 часа.
- Гайды: `MaterialEditor`, `MaterialAudience`, `GuideInsertEditor`,
  `guide_embeds.py`. Проверка оглавления проводится на странице материала:
  предпросмотр редактора его не показывает.

Все 26 HTML-блоков скомпилированы без диагностик. Три копируемых HTML-примера
из справочника дополнительно проверены отдельно; в самом тексте их код экранирован.

Браузерная проверка: 20 сценариев до/после на 1360×1000 и 390×844. Проверены
оглавления, переход фокуса, раскрытие пояснений, загрузка обоих снимков, отсутствие
горизонтального переполнения страницы и ошибок JavaScript. Скриншоты просмотрены:
колонки на телефоне становятся вертикальными, таблицы и плашки читаемы.

После публикации API вернул точные новые тексты, описания и те же аудитории всех
пяти материалов. Серверные деревья оформления совпали с проверенными локальными.
Фактические DTO повторно прошли 10 браузерных сценариев на двух размерах экрана.
Широкий тестовый набор приложения не повторялся: изменён только контент.

## Публикация и откат

Перед изменениями создан снимок SQLite через backup API. Скрипт проверил старые
контрольные суммы всех пяти публикаций и отсутствие чужих черновиков. Затем
выполнены предпросмотр, сохранение черновиков, отдельная публикация и чтение
результата. Каждый шаг использовал `expected_revision`. Все пять материалов
получили ревизию 6. Контрольные суммы опубликованных текстов обновлены в
[catalog.json](../user-guides/catalog.json).

ККР сохранил аудиторию `leadership`, остальные четыре — `everyone`. Новые материалы
и файлы не создавались; прежние ссылки и два изображения трекера используются
повторно. Бот, тестовый сайт и другие публикации не менялись.

Предыдущие DTO и ревизии сохранены в закрытом каталоге операции на сервере.
Подготовлен `rollback`: проверка актуальной ревизии, восстановление прежнего
текста и описания через API, публикация и проверка результата. Восстановление всей
БД для отката текста не требуется и затёрло бы последующие действия пользователей.

DTO, контрольные суммы, сравнения, браузерные снимки и три аудита с указателями
на код. Итоговый браузерный запуск:
`.local/logs/local-20261112T011424Z-cc99a0/`.
