          назначения председателя собственным заместителем и автоматической выдачей/отзывом глобального статуса admin.

      • GET /api/events/{id}, PATCH /api/events/{id}

      • GET /api/events/{id}/subevents, POST /api/events/{id}/subevents
      • GET /api/subevents/{id}, PATCH /api/subevents/{id}
  • Управление составом и правами:
      • PUT /api/events/{id}/leaders (тачки, глава блока / зам)

      • PUT /api/subevents/{id}/organizers (ответственный за мероприятие / зам, тачки)
      • PUT /api/blocks/{id}/leader (только тачки)

      • GET / PUT / DELETE /api/events/{id}/meeting
      • GET / PUT / DELETE /api/subevents/{id}/meeting
      • Права: просмотр доступен только участникам (ответственным/замам/организаторам, главе блока и тачкам). Редактирование и удаление — только ответственным/замам   
      мероприятия/подмероприятия и тачкам.

      • POST /api/season-corrections (только тачки, валидация ревизии и целевого сезона)
