# Правила работы в profkom_web

## Только локальная работа

Явное правило владельца проекта от 2026-10-19: **никакая работа по этому
проекту не выполняется нигде, кроме локальной машины пользователя, без его
предварительного явного одобрения.**

- Код, команды, проверки, базы данных, серверы и сборки запускать локально.
- Без отдельного явного разрешения не подключаться по SSH, в том числе к
  `neuroh100` / `neuro-8h100.klg.yp-c.yandex.net`, и не использовать удалённые
  исполнители, облачные задачи, внешние CI/CD или окружения развёртывания.
- Без такого разрешения не переносить проектные данные на другие машины,
  не выполнять удалённые Git-операции, деплой и обращения к реальным VK/S3
  или другим внешним сервисам проекта. Локальные тесты используют localhost,
  синтетические данные и подмены внешних сервисов.
- Общее поручение реализовать, проверить или продолжить работу не является
  одобрением внешнего окружения. Разрешение должно явно определять внешнее
  окружение и действие.
- Требование остановить локальные серверы сохраняется до нового поручения
  на их запуск или проверку, для которой запуск необходим. Не запускать их
  заново при простом разборе статуса.

Применять проектный skill `.agents/skills/profkom-web/SKILL.md`; сохранять
существующие изменения пользователя и следовать проверочным правилам проекта.
