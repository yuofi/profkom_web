## Поставка и эксплуатация

Реальный VK, S3 и производственные данные в эту работу не включались. Перед поставкой остаются следующие действия:

| Действие | Что требуется | Критерий закрытия |
| --- | --- | --- |
| Сопоставить существующие роли/личности | Проверенные user_id, block_id HR/мастеров и внешние VK subject; репетиция `migrate_v13.py` на резервной копии | Повторный apply сохраняет ID/числа/тексты; quick_check=ok; отчёт разрешает неоднозначности без сопоставления по ФИО |
| Проверить реальные VK/S3 | Настройки провайдера, приватная политика bucket/CORS; новые загрузки проходят contextual intent/complete | Вход связывает ожидаемый subject; PUT/HEAD/GET работают, неподтверждённый/чужой файл запрещён, после утраты роли GET не выдаётся |
| Убрать прежний публичный доступ к объектам | Политики/ACL старых объектов и срок жизни ранее опубликованных URL | Старый бессрочный URL больше не открывает закрытый объект; новый API выдаёт короткую ссылку только после ACL |
| Установить расписание retention | Команда/cron из ACCOUNT_RETENTION.md, явный путь БД, политика резервных копий | Успешные dry-run/повторный apply на копии, ежедневный job с наблюдаемым результатом и повтором удаления объектов после сбоя |
| Пройти live UI-приёмку поставленной версии | Полный desktop/mobile процесс с фактическими ролями/данными после согласованного деплоя | Сценарии UI-01/02 и пользовательские пути проходят в развёрнутом окружении |

Push, деплой, миграция настоящей БД, выдача настоящих прав и установка расписания не выполнялись.
