# Аудитория гайдов

У гайда блока (`kind=guide`, `owner_block_id`) есть три значения `audience`:

| Значение | Читатели опубликованного текста |
| --- | --- |
| `block` | Участники и руководство своего блока, председатель и заместители. |
| `everyone` | Все действующие, незаблокированные аккаунты сайта. |
| `leadership` | Председатель и его заместители, мастера блоков, главорги мероприятий, ответственные за части мероприятий и заместители этих руководителей. |

Права проверяются сервером при каждом запросе: каталог, материал, старый ID,
метаданные и байты файлов. Назначение и снятие роли действует без изменения гайда.
Архивный блок не даёт право руководителя. Обычный владелец очереди не получает
доступ к `leadership` только за владение очередью; назначение редактором материала
также не обходит эту аудиторию. Сервисный аккаунт имеет доступ по общей политике.

Изменение: `PUT /api/materials/{id}/audience`, тело содержит `audience` и
`expected_revision`. Команда не сохраняет текст и не публикует черновик. У
общих документов и КМБ настройки аудитории нет. Право редактировать не расширяется:
новая аудитория разрешает чтение руководителям, а не изменение чужих материалов.

Проверки: `tests/test_guide_leadership_audience.py`, `test_guide_audience.py` и
frontend `material-workspace.test.tsx`.
