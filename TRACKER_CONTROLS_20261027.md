# Быстрые действия трекера — 2026-10-27

Изменения выполнены локально в `feature/tracker`, поверх второго этапа трекера.

## Выполнены пять правок

1. **Иконки и цвета.** Для типов «Задача», «Веха», «Эпик» используются единые иконки. Четыре приоритета имеют разные иконки и цвета: «Низкий», «Средний», «Высокий», «Срочный». Они показаны в шапке задачи, параметрах и списках.
2. **Меню по нажатию.** Нажатие типа или приоритета открывает компактное меню с текущим выбором. Сохранение отправляет только выбранное поле и версию задачи. Доступно любому текущему читателю, включая задачи закрытого сезона. Выбор вехи автоматически очищает плановое начало; оба изменения отражаются в истории за одну ревизию. Несовместимые связи эпика/вехи дают понятную ошибку, без частичного изменения задачи. Поддерживаются клавиатура, Escape и закрытие вне меню. При сохранении фокус сохраняется, повторный запрос блокируется.
3. **Чеклист для читателей.** Любой читатель может отметить отдельный существующий пункт. Текст, порядок и состав чеклиста редактируются по прежним правам. Новый endpoint проверяет версию задачи, принадлежность пункта и строгое булево значение; повтор текущей отметки не создаёт ревизию или историю. Устаревшая версия возвращает 409. История хранит фактического автора и полный упорядоченный diff чеклиста.
4. **Настоящее имя очереди в навигации.** Цепочка начинается с названия текущей очереди и ведёт на её страницу. Без родителя остаются два элемента: «Название очереди → ключ задачи»; с родителем — три: «Название очереди → название родительской задачи → ключ задачи».
5. **Управление из списков.** Иконки типа и приоритета находятся слева от ключа в общем списке и списке очереди. Клик, выбор пункта меню и управление клавиатурой не открывают строку задачи. Общая основа меню и иконок сохраняет одинаковое поведение со страницей задачи.

## Права и данные

`change_task_type`, `change_task_priority`, `toggle_task_checklist` выдаются каждому текущему читателю. Явный `starts_at`, включая null, остаётся под прежним правом редактирования планирования; полная замена чеклиста — под прежним правом редактирования описания. Смешанный PATCH с запрещённым полем отклоняется целиком.

`POST /api/tasks/{id}/checklist/{item_id}/toggle` принимает `expected_revision` и `checked`, возвращает полный Task. Публичные изменения не меняют часы, оценки, учётные даты, решения ККР или его приватные версии. Права утраченного доступа проверяются на каждом запросе. Схема SQLite в этой работе не менялась; новые зависимости не добавлялись.
