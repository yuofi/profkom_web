## Общая задача

Владелец уточнил: несколько исполнителей означают одну совместную работу, один статус и одну общую сдачу. Разную работу людей нужно разделять на самостоятельные задачи; родительские/зависимые задачи запланированы на следующий этап.

Публичный workflow хранится отдельно от личных расчётных исходов. Рабочие действия исполнителя не стирают частные коррекции учёта; приём/доработка руководителем используют существующие права, причины, оценку и защиту ревизий. Участники видят общий результат и текущий состав команды; личные часы/оценки доступны своим ролям. Подробности — [backend/docs/TRACKER_WORKFLOW.md](backend/docs/TRACKER_WORKFLOW.md).

Новые таблицы добавляются идемпотентно. Сохраняются ID/ссылки, исходные сдачи, индивидуальные результаты и вклады ККР. У старых задач со смешанными исходами сохраняется публичный снимок: скрытая корректировка оценки не меняет общий DTO, capabilities, дату обновления, историю и порядок задач. Несовместимое изменение такого старого исхода получает объяснимый409; прошлые оценки не переписываются. Полную неизвестную историю задним числом не создаём.

## Интерфейс

| Требование | Реализация и критерий закрытия |
| --- | --- |
| Нажатие на строку | Открывается задача; Enter/Space и модифицированный клик сохранены. Ссылка исполнителя ведёт на отдельный профиль, чип статуса открывает меню и не активирует строку |
| Фильтры как чипы | Поиск/назначение/статус/сезон/команда/исполнитель/незавершённые/просроченные отражаются в URL и чипах с крестиком; удаляется только выбранный фильтр, страницы сбрасываются |
| Масштаб списка | Серверный поиск по названию/ключу, фильтры, сортировка, total и cursor;20 строк на странице. Пустые необязательные параметры не отправляются как неверные числовые/enum значения |
| Страница задачи | Компактная шапка, путь/номер/автор/даты/копирование ссылки, описание слева и параметры справа. На узком экране параметры изначально свёрнуты. Дедлайн редактируется через существующую разрешённую форму |
| Общий статус | Меню и верхние действия вызывают реальные команды. Разрешены только переходы текущей роли и состояния; причины/приёмка не заменены произвольной записью статуса |
| Общая сдача | Один участник отправляет общий результат, в том числе только файлом. У всех текущих исполнителей один workflow; индивидуальные часы и оценки сохранены отдельно |
| Вкладки и порядок | Комментарии/вложения/история, новые или старые сначала; смена вкладки сохраняет несданный комментарий |
| Markdown | Панель форматирования, таблицыGFM, код/цитаты/списки/чеклисты, LaTeXвстроке/блоком, глаз первым слева, сохранение исходника/курсора/undo и русских шорткатов. KaTeX/CSS/шрифты локальные, rawHTML и доверенные команды не включены |
| Вложения | Отдельно файлы к постановке и общие сдачи. intent→PUT→complete→привязка→скачивание проверяются по текущему контексту и правам; незакреплённый черновик не становится общедоступным |
| История и ревизии | Публичная история только известных событий; скрытые коррекции не раскрываются. Старый URL переназначенного assignment не обходит текущую ревизию. Конфликт сохраняет ввод и позволяет сравнить/обновить данные |
| Профиль исполнителя | Новый адрес /contacts/:id показывает только существующую разрешённую проекцию справочника; чужие данные не редактируются, недоступный профиль не раскрывается |
| Заглушки | Родительские/связанные задачи, чеклисты сущностью, тип/приоритет/цели/наблюдатели/избранное, календарное представление и Гантт помечены как запланированные, без мнимой функциональности |
